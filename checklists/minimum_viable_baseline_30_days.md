# Minimum Viable Baseline (MVB) – 30-Day Deployment Plan

## Week 1
- Enable MFA tenant-wide
- Block legacy authentication
- Inventory privileged roles → enable PIM

## Week 2
- Deploy Windows/macOS compliance policies
- Configure baseline profiles (BitLocker/FileVault)
- Onboard devices to Defender

## Week 3
- Deploy Safe Links and Safe Attachments
- Configure anti-phish baseline
- Establish quarantine workflow

## Week 4
- Connect Microsoft 365 → Sentinel
- Enable core analytics rules
- Build 3 SOAR playbooks (disable forwarding, disable user, notify teams)
